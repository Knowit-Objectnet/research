# KAIROS

Presentasjoner og annet materiale fra KAIROS: Samspill mellom mennesker og AI som grunnsten for fremtidens arbeidsliv (2025–2029). Knowit leder prosjektet, SINTEF er forskningsleder, og det er støttet av Norges forskningsråd (prosjektnr. 357147).

Om prosjektet: https://research.lab.knowit.no/projects/kairos-samspill-mennesker-og-ai/

## Struktur

Én mappe per arrangement, navngitt `ÅÅÅÅMMDD_type_tittel` som i `transformit/`. Hver mappe har en `readme.md` med program og foredragsholdere. Last bare opp presentasjoner foredragsholderen har godkjent at deles.
